# Cpolar 内网穿透说明

官方后台与下载：https://www.cpolar.com/

## 1. 为什么使用 Cpolar
- 用于将本地开发的 Spring Boot 服务（端口：`8092`）映射到公网。
- 支持 **支付宝沙箱异步回调通知（notify_url）** 与 **微信公众号交互（握手验签与事件推送）**。

## 2. 启动与配置步骤
1. 打开本地 Web UI：`http://127.0.0.1:9200`
2. 创建隧道：
   - 隧道名称：`s-pay-mall`
   - 协议：`http`
   - 本地地址：`8092`
   - 地区：`China` / `China VIP`
3. 查看公网地址：
   - 在 **状态 -> 在线隧道列表** 查看分配的域名（支持 http 与 https）。

## 3. 项目关联配置
- **支付宝异步回调**：`s-pay-mall-web/src/main/resources/application-dev.yml` 中的 `alipay.notify_url`
- **微信公众平台**：微信测试号接口配置 URL：`https://225b91df.r15.vip.cpolar.cn/api/v1/weixin/portal/receive`
